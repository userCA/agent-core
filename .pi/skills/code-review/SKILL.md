# Code Review Skill

When reviewing code:
1. Check for obvious bugs (null pointer, off-by-one, resource leaks)
2. Verify error handling paths
3. Look for performance issues (unnecessary allocations, nested loops)
4. Suggest idiomatic improvements for the language
5. Flag security issues (injection, unsafe deserialization)

Use the `read` tool to inspect files, then provide structured feedback.
