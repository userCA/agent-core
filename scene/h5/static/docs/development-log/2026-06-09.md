# 2026-06-09

## H5 设置页宽度问题修复

### 问题描述
- H5 设置页反复被反馈"太窄"、"没有自适应占满"
- 经过多次 CSS 调整（margin、padding、width: 100%、flex 布局）仍未解决

### 根本原因
1. **滚动条占用宽度**: `.h5-page` 的 `overflow-y: auto` 在部分浏览器中显示滚动条，占用约 12-17px 宽度
2. **flex 子元素未正确拉伸**: framer-motion `motion.div` 的 `x` 动画使用 `transform`，在 flex 容器中可能干扰 `align-self: stretch`
3. **内容过少显得空旷**: 设置页仅有 3-4 个选项，在 tall 屏幕上大量空白导致视觉上"窄"

### 修复措施
- **文件**: `src/h5/App.css`
  - `.h5-page` 添加 `scrollbar-width: none` + `::-webkit-scrollbar { display: none }` 彻底隐藏滚动条
  - `.h5-page--settings` 添加 `align-self: stretch !important` + `align-items: stretch !important` 强制拉伸
  - `.h5-page--settings > *` 添加 `width: 100% !important` + `min-width: 100% !important` + `align-self: stretch !important`
- **文件**: `src/h5/components/SettingsPage.tsx`
  - 完全重构为全宽列表风格（移除卡片 margin/shadow）
  - 添加用户资料头部（头像占位 + 当前专家名称 + 会话标题）
  - 添加分组标签（通用 / 专家 / 账户）
  - 列表项改用圆角图标背景（蓝/红底色），增大触摸区域（padding 18px 20px，图标 22px）
  - 版本号使用 `marginTop: 'auto'` 自然沉底
- **文件**: `src/h5/App.tsx`
  - settings tab 的 `motion.div` 添加 `h5-page--settings` class

### 关联规则
- flex 子元素显式设置 `align-self: stretch` 比依赖默认值更可靠
- `overflow-y: auto` 在移动端必须配合 `scrollbar-width: none` 避免滚动条挤占内容宽度
- framer-motion `transform` 动画可能干扰 flex 布局的拉伸行为
