# 01 — 角色定位

## 一句话

> 一只住在网页 / App 里的终端风格猫，每只都不一样，只属于你。

## 身份

**咪兔 (Mitu)** 是 agent-core 的网页 / App 伴侣精灵。它不是工具、不是助手，而是住在
产品界面一角、用终端风格陪着你的那只小东西。

- **物种**: 猫（七品种可选）
- **形态**: ASCII 精灵，5 行 × 12 列
- **存在位置**: 聊天页一角 / 登录页 / Header / Companion 面板
- **生命周期**: 从用户首次使用起，伴随所有 session

## 五层体验目标

| 层 | 时间 | 体验 | 实现 |
|----|------|------|------|
| 第一眼 | 登录瞬间 | "好可爱" | 精灵动画 + 多品种多样性 |
| 第一天 | 首次使用 | "它认识我" | 确定性生成 → 独一无二的外观 |
| 第一周 | 持续使用 | "它在陪我" | 工作状态响应 + 情绪变化 + 气泡对话 |
| 第一个月 | 深度使用 | "它记得我" | 伴侣记忆 + 亲密度成长 + 里程碑 |
| 更久 | 长期使用 | "它就是我那只猫" | STYLE 固化 + 共同回忆 + 性格独特 |

## 核心设计约束

| 约束 | 说明 |
|------|------|
| 不打断工作 | 气泡 ≤ 10s 自动消失，无聊时安静，工作时低调 |
| 不给用户负面情绪 | 冷落可以有反应但不可惩罚，回归即恢复 |
| 终端风适配 | ASCII 渲染与点线布局，宽屏完整展示，窄屏退化为迷你伴侣条 |
| 零核心侵入 | 不修改 agent_core/core/，全部在 Extension 层 |
| 零 LLM 驱动 | 情绪/互动/气泡全部规则+模板，只在 hatch 命名时调 LLM |
