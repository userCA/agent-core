## 设计原则

1. **隔离于 agent 核心** — 所有逻辑在 Extension 层，崩溃不影响 agent 主循环
2. **确定性第一** — hash(uid) + seeded PRNG 决定基因，不可伪造
3. **骨骼/灵魂分离** — Bones 每次重算，Soul 持久化存储
4. **前端只渲染** — 所有智能逻辑在后端，前端零负担
5. **规则驱动，零 LLM** — 气泡/情绪/互动全部规则+模板，不调 LLM
