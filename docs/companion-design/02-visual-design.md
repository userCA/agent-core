# 02 — 视觉设定

## 品种体系

### 橘猫 (orange_tabby) — weight 30%
```
   /\_/\     
  ( o   o )  
  (  ω   )   
  (")_(")    
```
- 额头纹: `/\` 型条纹
- 体型: 圆润偏胖
- 性格倾向: 佛系、贪吃、好脾气
- 稀有度限定: 无（全部稀有度可 roll）

### 奶牛猫 (tuxedo) — weight 20%
```
   /\_/\     
  ( o   o )  
  ( ◇   ◇ )   ← 白领结花纹
  (")_(")    
```
- 额头: 菱形白斑
- 胸: 白色领结形
- 性格倾向: 活泼、好奇、有点傻
- 稀有度限定: 无

### 三花猫 (calico) — weight 15%
```
   /\/\/\     ← 不对称耳色
  ( o   ● )   ← 异色眼眶
  (  ω   )    
  (")_(")     
```
- 毛色: 橙+黑+白三色斑
- 特征: 不对称性——耳色左右不同，眼眶异色
- 性格倾向: 傲娇、独立、偶尔黏人
- 稀有度限定: uncommon+ (三花几乎都是母猫基因)

### 暹罗猫 (siamese) — weight 15%
```
   /\_/\     
  ( `   ´ )   ← 杏仁眼、上挑
  (  ▽   )    ← 三角形小嘴
  (")_(")     
```
- 脸型: 瘦长优雅
- 重点色: 耳尖/脸侧/爪尖深色
- 性格倾向: 话唠、八卦、聪明
- 稀有度限定: 无

### 黑猫 (black_cat) — weight 10%
```
   /\_/\     
  ( ◉   ◉ )   ← 大黄眼（最亮）
  (  ~   )    ← 神秘微笑
  (")_(")     
```
- 全身暗色调，眼睛是最亮的元素
- 性格倾向: 神秘、高冷、偶尔撒娇
- 稀有度限定: 无
- 特殊: 暗处帧——背景融合，只剩眼睛

### 布偶猫 (ragdoll) — weight 8%
```
  ~/\___/\~   ← 长毛耳饰
  ( ◉   ◉ )   ← 蓝眼
  (  ω   )    
 ~(")___(")~  ← 长毛蓬蓬
```
- 体型: 蓬松长毛，15×6 列（比标准宽 1 列）
- 眼睛: 湛蓝色
- 性格倾向: 温柔、安静、粘人
- 稀有度限定: rare+

### 折耳猫 (scottish_fold) — weight 2%
```
   __/\__     ← 折耳（耳尖向前折）
  ( o   o )   
  (  ω   )    
  (")_(")     
```
- 耳朵: 向前折叠，区别于所有品种
- 脸型: 圆脸大眼
- 性格倾向: 胆小、温顺、喜欢被夸
- 稀有度限定: epic+（2% 基础 + 稀有度过滤 = 极稀有）

## 眼睛系统

所有品种共用眼睛池。`bones.eye` 决定**默认**眼睛，情绪触发可**临时覆盖**。

| 字符 | 名称 | 默认可用 | 性格暗示 |
|------|------|:--:|------|
| `·` | 眯眯眼 | ALL | 慵懒、淡定 |
| `o` | 圆眼 | ALL | 好奇、天真 |
| `-` | 闭眼 | ALL | 享受、睡觉 |
| `◉` | 大圆眼 | uncm+ | 震惊、警觉、专注 |
| `✦` | 星光眼 | rare+ | 闪亮、稀有 |
| `♥` | 爱心眼 | epic+ | 喜欢、满足 |
| `▼` | 三角眼 | leg+ | 不满、生气 |
| `´` | 杏仁眼 | 暹罗独有 | 优雅、上挑 |

## 配饰双轨系统

### 第一轨: 帽子 (HATS)

```
none       — 无
crown      — \^^^/    皇冠
tophat     — [___]    礼帽
propeller  —  -+-     竹蜻蜓
halo       — (   )    光环
wizard     —  /^\     巫师帽
beanie     — (___)    毛线帽
tinyduck   —  ,>      小鸭子
```

稀有度过滤:
- common → 仅 none
- uncommon → none + 随机 2 个普通帽
- rare → 大部分
- epic+ → 全部

### 第二轨: 猫配饰 (CAT_ACCENTS)

渲染在脖子/身体行，与帽子**可叠加**。

```
none           — 无
bell_collar    — 「 o 」    铃铛项圈
bow_tie        — 「◇◇◇」    蝴蝶结
fish_treat     — 「><>」     叼小鱼干
yarn_ball      — 「 @~」     毛线球
ribbon         — 「><」      缎带
glasses        — 「◎◎」     圆框眼镜
cape           — 「||」      小披风
```

稀有度过滤: common → none, uncommon → 普通 3 个, rare+ → 全部

### 组合示例

```
   \^^^/        ← crown (帽子轨)
   /\_/\     
  ( ◉   ◉ )   
  o(  ω   )o    ← bell_collar (配饰轨, 叠加在身体行)
  (")_(")    
   橘子
```

## 稀有度视觉差异速查

| 属性 | common | uncommon | rare | epic | legendary |
|------|--------|----------|------|------|-----------|
| 帽子 | none | 普通帽 | 大部分 | 全部 | 稀有帽 |
| 配饰 | none | 普通 | 大部分 | 全部 | 传说配饰 |
| 眼睛池 | `·` `o` `-` | +`◉` | +`✦` | +`♥` | +`▼` |
| 闪亮概率 | 1% | 1% | 2% | 5% | **100%** |
| 动画帧数 | 3 | 3 | 4 | 5 | 6 |
| 名字颜色 | 灰 | 绿 | 蓝 | 紫 | 金 |
| 粒子特效 | - | - | - | `＊` | `＊ ✦ ＊` |
| 专属配饰 | - | - | - | - | 星光项圈 |

### 闪亮 (Shiny)

- 判定: `rng() < 0.01`，与稀有度独立（传说级强制 true）
- 视觉: 名字金色渲染、眼睛反色、帧间 5% 概率出现 `＊` 粒子
- 稀有度: 闪亮 × legendary → "闪亮传说"——名字彩虹色渐变
