咪兔 Header SVG 收敛版预览

这一版不是“把猫画得更细”，而是把 SVG 收回到适合 Header 的轻结构。 核心思路是：猫保持强轮廓识别，SVG 负责边界、状态点、气泡和微弱终端风氛围。

A. 极简常驻态
calm
.
默认态只保留猫、情绪词、状态点，不显示气泡框、房间、小灯、小窝。
B. 反馈常驻态
happy 修好了喵
o
有反馈时才出现短气泡；依旧不放房间物件，只让猫和反馈本身成为主角。
C. 深夜态
sleepy 都这个点了...zz
*
深夜态只允许少量暗调和一个状态星点，不引入整块夜景或大量装饰。
D. 轻展开浮层
happy
*
┌─ Mitu ───────────────────┐
│ mood: happy              │
│ want: 想被摸摸           │
│ goal: 工具 3 次 / 摸摸 2 次 │
└──────────────────────────┘
pet feed buddy
浮层才使用边框和摘要信息；常驻层本身仍然保持极简，不做小型 HUD。
