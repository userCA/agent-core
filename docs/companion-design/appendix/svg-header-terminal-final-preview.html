咪兔 Header 终版预览

这版是收口后的最终方向：Header 里保持轻量的 ASCII 猫与终端语法，SVG 只负责边界、气泡、状态点、连接件和 Dock 外壳。 小游戏统一收进一个可插拔的 `activity dock`，内部使用同一套 terminal lane 协议，因此既更像终端微面板，也更适合后续扩展。

这版比前一版多做了 4 个收敛优化：
`1.` 把小游戏统一成 `command + lane + result queue`，更像终端过程而不是卡片 UI
`2.` 把扩展性落到 `manifest`，后续新小游戏只换运行协议，不换 Header 壳层
`3.` 把可玩反馈收束到 `pond / bar / log / keycap` 四块，直观但不拥挤
`4.` 继续让 SVG 只承担壳层和连接件，不把猫或游戏主体重新画成重插画
