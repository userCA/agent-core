# 附录 — 完整 ASCII 精灵帧库

## 帧 ID 定义

```
REST        = 0   # 标准坐姿/默认
TAIL_SWISH  = 1   # 尾巴摆动
WASH_FACE   = 2   # 洗脸/舔爪
STRETCH     = 3   # 伸懒腰
LOAF        = 4   # 面包卷 (揣手)
SLEEPING    = 5   # 打盹
HAPPY       = 6   # 开心/满足
EAR_PERK    = 7   # 竖耳 (警觉)
HEAD_TILT   = 8   # 歪头
CONCERNED   = 9   # 飞机耳/担心
LEGENDARY   = 10  # 传说独家帧
```

## 帧渲染规则

1. `{E}` 占位符替换为当前眼睛字符（bones.eye 或情绪覆盖）
2. 帽子覆盖帧0 的第 0 行（如帧0的第 0 行为空）
3. 配饰插入帧0 的身体行（第 3 行）
4. 闪亮粒子 `＊` 以 5% 概率（每 tick）在帧边缘随机出现
5. 所有帧使用等宽字体约束: 12 列宽 (布偶 14 列)
