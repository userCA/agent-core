咪兔 Header Inline Dock 终版预览

这版作为最终确定方向：小游戏 Dock 完全内嵌在 Header 栏里，不下探到聊天内容区域。 咪兔保持轻量 ASCII 主体，SVG 只负责边界、气泡和 Dock 外壳；小游戏则以一行终端式状态流存在，既简洁，也方便未来扩展。

Why This Final
这版作为最终确定方向，主要收敛在 4 点：
`1.` Minigame Dock 完全留在 Header 行内，不侵入聊天内容区
`2.` Dock 只保留一条终端式状态流，不做大面板，不堆内容
`3.` 玩法可扩展到 `fish / catch / tap`，但 UI 容器始终是一条统一的 inline dock
`4.` 视觉上仍然是“ASCII 猫 + SVG 壳层”，保持简约和终端感
