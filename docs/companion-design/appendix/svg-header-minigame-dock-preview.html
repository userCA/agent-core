咪兔 Header 小游戏 Dock 预览

这版把小游戏定义为 Header Companion 下的一层 Activity Dock，而不是把钓鱼直接塞进猫旁边。 SVG 继续只负责边框、连接件、状态点和轻氛围；真正的小游戏内容走“可插拔 lane”。 这样钓鱼可以接入，后续也能接拾荒、拍打、连击、记忆等其他小游戏，而不需要重做 Header 壳层。

C. 为什么原方案不直观 / 为什么 Dock 更适合扩展
不推荐: 把小游戏硬塞进猫旁边
cat ~~~~ ◎ ~~~~ + 鱼

问题是 Header 左侧会迅速变成一条功能带，猫、气泡、小游戏、结果全都挤在一行里。 钓鱼勉强能放，后续别的小游戏几乎没法复用。

推荐: teaser + 可插拔 Dock
slot 同一壳层 钓鱼 / 接物 / 连击 / 记忆

Header 里始终只有一个小游戏入口芯片，打开后才出现 Dock。Dock 自身只是一层统一壳， 内部 lane 才是具体小游戏模块，所以后续加别的小游戏只换 lane 内容，不换整体交互模型。
