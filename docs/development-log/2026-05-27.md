## #1 清理 loop.py：消除 _log 重复，提升模块内聚

**问题**：
- `logging.getLogger(__name__)` 在 retry 分支和 overflow 分支中各重复一次（两处行内赋值）
- `_tools_to_provider_format` / `_definition_to_openai` 是 provider 层的工具格式转换逻辑，放在核心 loop 中违反职责单一；之前被塞进 `providers/types.py` 又破坏了类型文件的纯类型职责

**修复**：
- `_log` 提升为模块级常量
- `tools_to_provider_format` 移至 `providers/base.py`，作为 `ModelProvider.stream()` 接口的配套工具——高内聚
- `providers/types.py` 保持纯 Pydantic 类型定义——职责单一

## #2 删除 dead code：`agent_loop_continue`、`trace_callback`、`_execute_tools` 包装

**问题**：
- `agent_loop_continue` 等价于 `agent_loop([], ...)`，唯一调用方是 agent.py
- `trace_callback` 定义了完整管道（AgentLoopConfig → Agent._run → loop），但无任何测试或 scene 使用。`TurnStart`/`TurnEnd` 事件已承载相同信息
- `_execute_tools` 包装函数为"避免循环导入"而存在，但 tool_runner.py 不导入 loop.py——无循环依赖

**修复**：
- 删除 `agent_loop_continue` 函数（loop.py）、导出（__init__.py）、调用（agent.py）
- 删除 `trace_callback` 字段（context.py）、两处调用（loop.py）、参数透传（agent.py）
- 删除 `_execute_tools` 包装，loop.py 模块级 import `execute_tools` 后直接调用
- 消除 `max_turns` 中间变量，import 分组修正
