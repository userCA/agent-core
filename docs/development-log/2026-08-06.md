## HTTP SSE: /agents CRUD + agent_id on chat/sessions

**类型**：feat（http_sse / agents）

**关联**：[`docs/superpowers/plans/2026-08-05-agent-definition-isolation.md`](../superpowers/plans/2026-08-05-agent-definition-isolation.md)

### 变更摘要

| 区域 | 文件 | 说明 |
|------|------|------|
| API | `scene/http_sse/server.py` | `GET/POST/DELETE /agents`；`resolve_agent_request`；`chat_stream`/`list_sessions`/`get_session`/`export_session`/`delete_session`/`abort` 支持 `agent_id` 参数 |
| Manager | `scene/http_sse/manager.py` | `get_or_create` 解析 agent/persona（agent_id 优先）；`_should_rebuild` 对比 `_agent_id`；`_assert_owner` agent 绑定校验（403）；`list_sessions`/`delete_session` 支持 `agent_id` |
| Assistant | `scene/http_sse/chat_assistant.py` | `__init__` 存 `_agent`；create 时 `SessionHeader` 写入 `agent_id` |
| 测试 | `tests/scene/test_agent_http_api.py` | 新增 11 passed |

### 设计决策

- **不做** Persona → AgentDefinition 合成：`Persona.enabled_tools` 是工具**名称**扁平白名单（含 MCP tool 名），而 `AgentDefinition.tools` 按 MCP **server** 名选择——合成会静默丢失全部 MCP 工具。旧客户端只传 `persona_id` 仍走 persona 兼容路径。
- 仅传 `persona_id` 且与已有 Agent 同名时，Agent 优先（V6 兼容 + 内部 AgentDefinition 优先）。
- 已存在会话禁止改绑到另一个 agent_id：`_assert_owner` 比对 `header.agent_id`，不匹配即 403（重建需新 session）。

## HTTP SSE: connectors 支持 shared / per-agent scope

**类型**：feat（http_sse / connectors）

**关联**：[`docs/superpowers/plans/2026-08-05-agent-definition-isolation.md`](../superpowers/plans/2026-08-05-agent-definition-isolation.md) Task 4.2

### 变更摘要

| 区域 | 文件 | 说明 |
|------|------|------|
| 工具层 | `agent_core/tools/mcp_tool.py` | 新增 `_resolve_mcp_file(cwd)` 私有解析器（与 loader 对称：`.pi/mcp/shared.mcp.json` 优先，否则根 `.mcp.json`）；四个 writer（`read/write_mcp_json_raw`、`add/remove_mcp_server_to_json`）新增 `path=` kwarg，读写与 loader 解析一致，修复「shared 存在时 POST /connectors 静默写到根目录」的遗留问题 |
| 池层 | `agent_core/tools/mcp_pool.py` | 新增 `reload_private(agent_id)`：drop + stop 已缓存私有 manager，再 `ensure_private` 从磁盘重载 |
| Manager | `scene/http_sse/manager.py` | 新增 `reload_private(agent_id)`（`_mcp_pool` 未启动时 no-op） |
| API | `scene/http_sse/server.py` | `/connectors` 四个路由（POST/GET/DELETE/health）新增 `scope=shared\|agent` + `agent_id`；agent scope 读写 `.pi/mcp/agents/<id>.mcp.json` 并 reload_private；两种 scope 变更后均失效 `_capabilities_cache` |
| 测试 | `tests/scene/test_connectors_scope.py` | 新增 10 passed |

### 设计决策

- shared connectors 沿用 `cwd=manager._cwd`（writer 内部解析到 shared/root）；agent connectors 用 `path=_agent_mcp_path(agent_id)` 直写显式文件，与 `_knowledge_dir` 同一 agent_id 校验 regex（`^[a-zA-Z0-9_-]+$`）。
- `GET /connectors`（agent scope）通过 `ensure_private` 惰性加载；缺文件时 `parse_mcp_json` 返回空 → 空列表，不报错。
- 向后兼容：既有调用方（`scene/h5/server.py` 等）仍以 `cwd=` 位置/关键字传参，签名新增 `path` 为纯追加。
