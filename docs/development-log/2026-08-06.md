# 2026-08-06

## HTTP SSE: /agents CRUD + agent_id on chat/sessions

**类型**：feat（http_sse / agents）

**关联**：[`docs/superpowers/plans/2026-08-05-agent-definition-isolation.md`](../superpowers/plans/2026-08-05-agent-definition-isolation.md)

### 变更摘要

| 区域 | 文件 | 说明 |
|------|------|------|
| API | `scene/http_sse/server.py` | `GET/POST/DELETE /agents`；`resolve_agent_request`；`chat_stream`/`list_sessions`/`get_session`/`export_session`/`delete_session`/`abort` 支持 `agent_id` 参数 |
| Manager | `scene/http_sse/manager.py` | `get_or_create` 解析 agent/persona（agent_id 优先）；`_should_rebuild` 对比 `_agent_id`；`_assert_owner` agent 绑定校验（403）；`list_sessions`/`delete_session` 支持 `agent_id` |
| Assistant | `scene/http_sse/chat_assistant.py` | `__init__` 存 `_agent`；create 时 `SessionHeader` 写入 `agent_id` |
| 测试 | `tests/scene/test_agent_http_api.py` | 新增 11 passed |

### 设计决策

- **不做** Persona → AgentDefinition 合成：`Persona.enabled_tools` 是工具**名称**扁平白名单（含 MCP tool 名），而 `AgentDefinition.tools` 按 MCP **server** 名选择——合成会静默丢失全部 MCP 工具。旧客户端只传 `persona_id` 仍走 persona 兼容路径。
- 仅传 `persona_id` 且与已有 Agent 同名时，Agent 优先（V6 兼容 + 内部 AgentDefinition 优先）。
- 已存在会话禁止改绑到另一个 agent_id：`_assert_owner` 比对 `header.agent_id`，不匹配即 403（重建需新 session）。
