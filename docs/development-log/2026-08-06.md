## HTTP SSE: /agents CRUD + agent_id on chat/sessions

**类型**：feat（http_sse / agents）

**关联**：[`docs/superpowers/plans/2026-08-05-agent-definition-isolation.md`](../superpowers/plans/2026-08-05-agent-definition-isolation.md)

### 变更摘要

| 区域 | 文件 | 说明 |
|------|------|------|
| API | `scene/http_sse/server.py` | `GET/POST/DELETE /agents`；`resolve_agent_request`；`chat_stream`/`list_sessions`/`get_session`/`export_session`/`delete_session`/`abort` 支持 `agent_id` 参数 |
| Manager | `scene/http_sse/manager.py` | `get_or_create` 解析 agent/persona（agent_id 优先）；`_should_rebuild` 对比 `_agent_id`；`_assert_owner` agent 绑定校验（403）；`list_sessions`/`delete_session` 支持 `agent_id` |
| Assistant | `scene/http_sse/chat_assistant.py` | `__init__` 存 `_agent`；create 时 `SessionHeader` 写入 `agent_id` |
| 测试 | `tests/scene/test_agent_http_api.py` | 新增 11 passed |

### 设计决策

- **不做** Persona → AgentDefinition 合成：`Persona.enabled_tools` 是工具**名称**扁平白名单（含 MCP tool 名），而 `AgentDefinition.tools` 按 MCP **server** 名选择——合成会静默丢失全部 MCP 工具。旧客户端只传 `persona_id` 仍走 persona 兼容路径。
- 仅传 `persona_id` 且与已有 Agent 同名时，Agent 优先（V6 兼容 + 内部 AgentDefinition 优先）。
- 已存在会话禁止改绑到另一个 agent_id：`_assert_owner` 比对 `header.agent_id`，不匹配即 403（重建需新 session）。

## chore: 示例 AgentDefinitions 与 mcp path layout

**类型**：chore（agents / mcp）

**关联**：[`docs/superpowers/plans/2026-08-05-agent-definition-isolation.md`](../superpowers/plans/2026-08-05-agent-definition-isolation.md) Task 4.3

### 变更摘要

| 区域 | 文件 | 说明 |
|------|------|------|
| 配置 | `.pi/agents/support.json` | 客服助手示例：`shared_mcp=["tavily","amap"]`，builtin 白名单（read/write/edit/bash/ls/find/grep/confirm/show_widget），knowledge 空块示例 |
| 配置 | `.pi/agents/analyst.json` | 数据分析师示例：`shared_mcp=["tavily"]`（研究为主、不含 amap），`knowledge.private=["market-research"]` 演示私有 KB 字段 |
| 配置 | `.pi/mcp/shared.mcp.json` | §8 迁移：由根 `.mcp.json` 复制（含真实 key），保持 gitignored（本地生效，不提交） |
| 构建 | `.gitignore` | `.pi/*` + `!.pi/agents/` 使示例 AgentDefinition 可提交（镜像 personas 追踪方式）；mcp/知识库等运行时数据仍忽略 |

### 设计决策

- `.gitignore` 采用 `.pi/*` 而非 `.pi/`：git 不支持在已排除的父目录内重新包含文件（"It is not possible to re-include a file if a parent directory of that file is excluded"），`!.pi/agents/` 只有配合 `.pi/*` 才能生效。`.pi/mcp/shared.mcp.json` 由 `.pi/*` 命中，真实 key 不进入版本库。

### 验收

- `python -c "from agent_core.resources.agents import get_agent, load_agents; print([a.id for a in load_agents(cwd='.')]); print(get_agent('support', cwd='.').tools.shared_mcp); print(get_agent('analyst', cwd='.').knowledge.private)"` → `['analyst', 'support']` / `['tavily', 'amap']` / `['market-research']`
- `git check-ignore -v .pi/agents/support.json` → 不忽略；`git check-ignore -v .pi/mcp/shared.mcp.json` → `.gitignore:23:.pi/*`（仍忽略）
- `pytest tests/resources/test_agents.py -q` → 8 passed
