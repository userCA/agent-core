**关联**：[`docs/superpowers/plans/2026-08-10-dynamic-workflows.md`](../superpowers/plans/2026-08-10-dynamic-workflows.md) Task 1–11 / 14；[`docs/superpowers/specs/2026-08-10-dynamic-workflows-design.md`](../superpowers/specs/2026-08-10-dynamic-workflows-design.md)

### 变更摘要（全模块）

| 区域 | 文件 | 说明 |
|------|------|------|
| 类型 | `agent_core/workflows/types.py`、`errors.py` | WorkflowMeta/Options/Progress/Checkpoint/RunResult；WorkflowError/SandboxError/CheckpointError/QuotaExceeded |
| 沙箱 | `agent_core/workflows/sandbox.py` | AST 白名单：`validate_workflow_source` + `build_sandbox_globals` |
| 运行时 | `agent_core/workflows/runtime.py` | WorkflowContext：phase/log/agent/pipeline；配额与 phase 输出 helpers |
| 持久化 | `agent_core/workflows/store.py` | CustomEntry(`workflow_checkpoint`) 读写 |

| 配方 | `agent_core/workflows/recipes/*.py` | fanout-synthesize、adversarial-review 内置示例 |
| 导出 | `agent_core/workflows/__init__.py` | 公共 API 导出 |
| 测试 | `tests/workflows/*` | 沙箱、runtime、store、loader、runner/checkpoint、patterns、tool/factory |
| 文档 | `docs/design.md` | §1.2 包布局 + §1.5 Harness-in-Tool 与 multi_agent/planning 边界 |
| 文档 | `docs/superpowers/specs/2026-08-10-dynamic-workflows-design.md` | 状态 → 已落地 |
| 文档 | `docs/superpowers/plans/2026-08-10-dynamic-workflows.md` | Task 1–11、14 勾选完成 |

### 架构要点

- **Harness-in-Tool**：不改 `core/loop.py`；`run_workflow` 注入主编排器，中间态卸载到脚本运行时 + checkpoint
- **沙箱**：受限 Python DSL，禁 import / 危险调用；patterns 只读注入
- **Checkpoint**：phase 边界持久化，支持 resume；配额 / abort / progress 计数加固（Task 9）
