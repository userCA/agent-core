## C5：L2 SemanticCompress（MVP）

**类型:** Context / 信噪比  
**关联:** `docs/agent-engineering-optimization.md` C5

### 变更摘要

| 区域 | 文件 | 变更 |
|------|------|------|
| 库 | `compaction/semantic_compress.py` | `semantic_compress` + 结构化 fallback（`__fallbackTruncated`） |
| 库 | `artifacts/extension.py` | ≥`compress_min` 走 L2；`__preview` 永远是原始 substring |
| Scene | `artifacts_config.py` | `ENABLE_SEMANTIC_COMPRESS=1`；可调 min/target |
| 测试 | `tests/compaction/test_semantic_compress.py` + artifact 扩展测 | LLM / fallback / preview 不改写 |

### 行为

- 正文仍进 L1 store；LLM 只看 summary（≤ target，默认 2000）
- 无 `compress_fn` 或 LLM 失败 → JSON 结构化截断，禁止裸截断作为 L2 路径
- `preview` / `__preview` = 原文前缀（确定性），仅存 details，**不进** LLM envelope
- Scene 默认开启时若未注入 `compress_fn`，行为是 **structured fallback**（非 LLM 蒸馏）

```bash
ENABLE_SEMANTIC_COMPRESS=0   # 关闭 L2，仅 L1 substring summary
```

## C1 MVP：L1 ToolResultRefStore（artifact 外置）

**类型:** 新功能 / Context 工程  
**关联:** `docs/agent-engineering-optimization.md` C1、`docs/reference/agent_engineering.md` §3.2 L1

### 变更摘要

| 区域 | 文件 | 变更 |
|------|------|------|
| 库 | `agent_core/artifacts/*` | `ArtifactStore` / `InMemoryArtifactStore`、`ArtifactExternalizeExtension`、`create_artifact_extension` |
| Core | `core/messages.py` | `ToolResultMessage.details` 可选字段，承载 `__refId` 等元数据 |
| Core | `core/tool_runner.py` | 写入 details；after_hook 同时支持 dict / ToolResult 返回值 |
| Session | `session/persistence.py` | 持久化 tool_result 时保留 details |
| 测试 | `tests/artifacts/*` | store 往返、阈值外置、Harness e2e（LLM 只见 ref） |

### 用法（可选 Extension，Scene 默认未开）

```python
from agent_core.artifacts import create_artifact_extension

store, ext = create_artifact_extension(char_threshold=8000, summary_chars=2000)
harness = AgentHarness(..., extensions=[ext])
```

### 边界（MVP）

- 仅字符阈值；无数组元素阈值、无 L4 取回工具、无 bash 路径收敛
- InMemory：进程重启后全文丢失（ref 文案仍在 transcript）
- 外置时 **合并** 原有 `details` 顶层键（`exit_code` / `plan` / `urls` 等），不包进 `original_details`
