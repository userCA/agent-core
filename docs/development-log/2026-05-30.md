## 详细记录

### 35. 暗色主题对比度修复

**根因 1**：`--stone`(#636366) 在暗色 canvas(#1c1c1e) 上对比度仅 ~2.6:1，远低于 WCAG AA 的 4.5:1。
影响 9 处文本（`.tool-text` `.msg-label` `.welcome-subtitle` `.step-icon` `.step-detail` `.section-icon` `.empty-state-desc` `.card-icon`）。

**根因 2**：`--ink`=`--on-dark`=#f5f5f7 在暗色主题下相同，6 个元素使用 `background:var(--ink)` + `color:var(--on-dark)` 导致白底白字。
影响：`.btn-primary` `.send-btn` `.action-btn.active` `.scene-tab.active` `.filter-tab.active` `.tool-toggle.on`。

**根因 3**：Pages.css SVG chevron 硬编码 `#646262`，暗色表单上不可见。

**修复**：
- `--stone` → #8e8e93, `--ash` → #98989d, `--accent` → #409cff
- 6 处 `color:var(--on-dark)` → `color:var(--canvas)`（亮色=白/暗色=黑）
- SVG chevron → #8e8e93
- ConfirmDialog backdrop → `var(--backdrop)`

### 40. 飞书 Bot 渠道

`scene/feishu/` 新增飞书消息渠道，通过 `lark-oapi` SDK 的 WebSocket 长连接接收消息：

**文件结构：**
- `api.py` — HTTP API 客户端（token 管理、消息发送/回复/编辑），备用
- `server.py` — 主程序：独立线程跑 WS 连接 + `run_coroutine_threadsafe` 调度事件

**核心设计：**
- WS 客户端在独立线程（`lark.ws.Client.start()` 是阻塞的），避免与主 asyncio 事件循环冲突
- 事件处理采用 `asyncio.run_coroutine_threadsafe()` 从 WS 线程调度到主事件循环
- 共用 `SessionManager`，按 `feishu-{open_id}` 创建会话
- Modal 回复使用飞书卡片 JSON 2.0（`markdown` 块），多表格时降级为纯文本
- 事件处理复用 `scene/http_sse/events.py` 模式：`MessageUpdate.delta` → `TextDelta`

**踩坑记录：**
- `MessageEnd` 在 turn 初始化时就触发，不能作为退出信号，只能对 `AgentEnd` 中断
- `run_in_executor` 不支持 keyword-only 参数，需用 lambda 包装
- 飞书卡片限制每张最多 1 个 markdown 表格，2+ 表格报 `code=230099 err=11310`
- `ToolExecutionEnd` 属性是 `tool_name` 非 `tool_call_name`
- `lark-oapi` 依赖 `pycryptodome` 用于加解密

**P0/P1 优化（第二轮）：**
- P0: 智能消息格式 — 检测内容自动选择 text（表格）/ post（富文本）/ interactive（markdown 卡片），失败自动降级
- P0: 处理状态反应 — 已移除（emoji 类型 `Eyes` 不被飞书支持，需 `im:message_reaction` 权限）。当前使用纯文本 `⏳ 思考中...` 占位符
- P1: 消息去重持久化 — `.pi/feishu_seen_ids.json` 24h TTL + LRU 2048 条上限
- P1: 客户端分片聚合 — 飞书长消息拆分为多个事件时，0.6s 内自动合并文本

**踩坑记录（第二轮）：**
- `loop.run_in_executor` 不支持 keyword 参数，必须用 `_send(chat_id, text)` 纯位置参数或 lambda 包装
- 飞书 reaction emoji 类型名有限制（不是标准 Unicode 名），`Eyes` 返回 `231001 reaction type is invalid`
- `_send_card_sync` 函数重复定义导致老版本覆盖新版本 → 所有函数定义必须唯一
