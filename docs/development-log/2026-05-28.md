## #1 修复 SSE 流式输出被 agent_loop 缓冲的问题

**问题**：用户发送消息后前端长时间只显示 thinking dots，随后思考内容和模型结果一次性全部刷出，无流式体验。

**根因**：`agent_core/core/loop.py` 的重试机制中，`_stream_assistant` 产出的所有 `MessageUpdate`（`ThinkingDelta`、`TextDelta`）被收集到 `buffered` 列表，直到整个 LLM 流结束后才一次性 `yield`。这是为了支持失败重试时不让客户端看到残片输出，但以牺牲 100% 正常情况下的流式体验为代价。

**修复**：`loop.py` 中区分首次尝试与重试尝试：
- `retry_count == 0`：直接 `yield MessageStart` + `async for ... yield upd`，实时流式
- `retry_count > 0`：保持原有缓冲逻辑，避免客户端看到失败尝试的残片

**权衡**：若首次尝试失败且触发重试，客户端可能已看到部分输出。但重试是罕见场景（网络错误/限流），为极端情况牺牲常规交互的流式体验不合理。

**验证**：全部 244 个测试通过，包括重试相关测试。
