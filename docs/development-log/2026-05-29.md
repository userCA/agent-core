## #2 历史消息加载格式修复

**问题**：重新打开历史会话时，消息变成未渲染的纯文本；思考内容未折叠；工具调用信息丢失。

**根因**：`loadMessages()` 对 array 格式的消息内容直接 `JSON.stringify()`，且未从历史消息中提取 `<think>` 标签和 `type:"tool_call"` 内容。

**修复**（`client.ts`）：
- 新增 `extractTextContent()`：从 string 或 array（OpenAI format）中提取可显示文本
- 新增 `parseAssistantMessage()`：调用 `extractThinkSteps()` + `getDisplayableText()` 重建 steps，提取 `type:"tool_call"` 为 ToolStep

## #3 UI/UX 全面审计与 5 阶段优化

参考 OpenCode 设计原则（flat, minimal, monochrome, cream canvas #fdfcfc），执行 5 阶段优化：

### Phase 1：Color Tokenization
- `tokens.css` 新增 6 个 token：`--backdrop`, `--shadow`, `--focus-ring`, `--ink-hover`, `--danger-bg-subtle`, `--success-bg-subtle`
- 替换 15 处硬编码颜色值（`#0f0000`, `rgba(255,59,48,0.06)`, `rgba(48,209,88,0.06)`, `rgba(32,29,29,0.10)`, `rgba(0,0,0,0.35)`, `rgba(0,0,0,0.12)`）

### Phase 2：GPU-friendly Animations
- `Header.css` `pulseRing`：从 `box-shadow` 动画改为 `::after` 伪元素 + `transform: scale()` + `opacity`
- `StreamingMessage.css` `cursorBlink`：移除 `box-shadow` glow，保留纯 opacity 闪烁

### Phase 3：Micro-interactions
- `ChatInput.css`：textarea `transition` 从 `:focus` 移到 base class，hover/focus 均有平滑过渡
- `MessageBubble.css`：`.bubble` 添加 `transition`，`.bubble-user:hover` 变 `--ink-hover`，`.bubble-assistant:hover` 背景变 `--surface-soft` + 边框变 `--hairline-strong`

### Phase 4：`will-change` 优化
- `.welcome-logo`（logoFloat）、`.thinking-dot`（dotWave）、`.step-spinner`（spin）、`.section-spinner-icon`（spin）添加 `will-change: transform`

### Phase 5：Icon Size Standardization
- `Icon.tsx` 新增 `ICON_SIZES = { sm: 12, md: 16, lg: 20 }`
- `MessageBubble.tsx` 和 `Header.tsx` 中 7 处 `size={11}` 替换为 `size={ICON_SIZES.sm}`
