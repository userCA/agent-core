## #2 历史消息加载格式修复

**问题**：重新打开历史会话时，消息变成未渲染的纯文本；思考内容未折叠；工具调用信息丢失。

**根因**：`loadMessages()` 对 array 格式的消息内容直接 `JSON.stringify()`，且未从历史消息中提取 `<think>` 标签和 `type:"tool_call"` 内容。

**修复**（`client.ts`）：
- 新增 `extractTextContent()`：从 string 或 array（OpenAI format）中提取可显示文本
- 新增 `parseAssistantMessage()`：调用 `extractThinkSteps()` + `getDisplayableText()` 重建 steps，提取 `type:"tool_call"` 为 ToolStep
