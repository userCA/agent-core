## 聊天附件远端上传（Migu）

- **类型**：修复 / 增强
- **问题**：聊天「添加图片」原先走 base64；短剧/Agnes 无法用本地路径或 localhost URL 作为可拉取输入
- **改动**：
  - `agent_core/tools/remote_upload.py` — 调用 `MIGU_UPLOAD_URL`（默认咪咕 upload v1.1，`serviceType=100`，`sid` header）
  - `scene/common/upload_handler.py` — `/upload` 本地落盘 + 远端上传，返回 `url`
  - H5 `filesToContentBlocks` / HITL 图片字段改为先上传再传公网 URL
  - `message_converter` / Anthropic 支持 http(s) 图片 URL 直通
  - 短剧工具优先使用公网锚点 URL，并允许从用户消息图片 URL 填 `anchor_urls`
