## 多 Agent Harness（Orchestrator + delegate_task）

**类型:** 新功能 / Scene 接入  
**关联:** `docs/superpowers/specs/2026-07-20-multi-agent-harness-design.md`、`docs/superpowers/plans/2026-07-20-multi-agent-harness.md`

### 变更摘要

| 区域 | 文件 | 变更 |
|------|------|------|
| 库 | `agent_core/multi_agent/*` | Profile 注册、子 Agent 工厂/Runner、`delegate_task`、`create_multi_agent_harness` |
| Session | `agent_core/session/{store,inmemory,jsonl,sqlite}_store.py` | `SessionHeader.owner`、`list_sessions(owner=)`、`fork_session` |
| http_sse | `chat_assistant` / `events` / `manager` / `server` / `multi_agent_profiles` | 工厂接入、delegation SSE、owner 校验、级联删子会话 |
| http_sse 前端 | `DelegationCard` + `useSSE` / `BlocksRenderer` / store / types | 折叠委派卡 |
| h5 | 同上模式 + `multi_agent_profiles` | H5 SSE v1 的 `delegation.update` + 委派卡 |
| 测试 | `tests/multi_agent/*` | 工厂、Runner、SSE 映射、store fork/owner |

### 踩坑

1. H5 `useSSE` 用 `(evt).phase !== undefined` 识别 content；`delegation.update` 也有 `phase`，被误吞 → **先判断 `actionType`**
2. TraceCard 仅凭 `turnPhase === intermediate` 把流式 text 当成「工具」步 → **步骤仅限 think/tool/skill**

### 验证

```bash
pytest tests/multi_agent/ -q
# 浏览器：scene/h5 + http_sse 可见「专家协调完成 parallel」委派卡
```

## Plan-Execute（manage_plan + PlanCard）

**类型:** 新功能 / Scene 接入  
**关联:** `docs/superpowers/specs/2026-07-20-plan-execute-design.md`  
**规则:** 非 DAG；Harness-in-Tool；与 multi_agent 正交；Plan 附着 Session（`CustomEntry plan_snapshot` + `owner`）

### 变更摘要

| 区域 | 文件 | 变更 |
|------|------|------|
| 库 | `agent_core/planning/*` | `PlanStore`、`ManagePlanTool`、`install_planning`、上下文注入 Extension |
| http_sse / h5 | `chat_assistant` + `planning_config` | `ENABLE_PLANNING` 时注册工具与 prompt snippet |
| SSE | `scene/{http_sse,h5}/events.py` | `event: plan` / `actionType: plan.update` |
| 前端 | `PlanCard` + `useSSE` / TraceCard / BlocksRenderer | 折叠计划卡；跳过 `manage_plan` 普通工具卡 |
| 测试 | `tests/planning/*` | store、http_sse/h5 SSE 映射 |

### 踩坑

1. 与 delegation 相同：H5 `plan.update` 带 `phase`，必须在 content 分支之前处理 `actionType`
2. `manage_plan` 若走普通 tool 卡会重复展示 → 与 `delegate_task` 一样跳过

### 验证

```bash
pytest tests/planning/ -q
# ENABLE_PLANNING=1（默认）时多步任务应出现 Plan 卡；可与 ENABLE_MULTI_AGENT=1 同开
```
