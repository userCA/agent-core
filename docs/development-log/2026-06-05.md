## 60. 咪兔伴侣系统 Phase 1-5 完整实现

**类型**: 新功能 | **涉及文件**: 33 个（26 新建 + 7 修改）

### Phase 1 — 登录页伴侣（多帧动画 + 输入响应）
- `CompanionSprite.tsx`：5 moods × 3 frames，500ms idle sequence 驱动 fidget
- `LoginCompanion.tsx`：根据输入状态切换 sleeping/awake/happy/working
- `companion-store.ts`：Zustand store 管理 mood + bones + revealed
- `LoginPage.tsx`：静态 ASCII → LoginCompanion；`LoginPage.css` 移除迁移样式

### Phase 2 — 确定性用户专属伴侣
- `companion/bones.py`：FNV-1a hash + mulberry32 PRNG，roll_companion(uid)
- `companion/species.py`：稀有度/眼睛/耳朵/配饰/调色板枚举（append-only）
- `server.py`：`GET /api/companion/{uid}` 返回确定性 bones
- 前端 rarity 揭示动画，login 点击时调用 API

### Phase 3 — CompanionExtension 集成
- `extensions/companion.py`：实现 Extension Protocol，on_event 过滤 TurnStart/TurnEnd 等
- `server.py`：SSE 流 interleave companion 事件；`chat_assistant.py`：optional companion 参数
- `Header.tsx`：静态 logo → HeaderCompanion（streaming 时 working 帧）

### Phase 4 — 伴侣记忆 + 引路 NPC
- `companion/memory.py`：CompanionMemory（uid 作为 session_id，跨 session 持久化）
- `companion/observer.py`：SilentObserver（话题提取、工具历史、空闲检测）
- `companion/guide.py`：GuideNPC 规则引擎（欢迎/工具建议/超时提醒/随机贴士）
- `companion/templates.py`：BondLevel 四级 + 模板槽位填充（零 LLM）
- `companion/topic_extractor.py`：关键字提取 + 敏感词黑名单 + 长度校验
- 默认 InMemoryMemoryStore，构造注入 MemoryStore 即可切换持久化

### Phase 5 — 钓鱼小游戏（种子+重放）
- `companion/minigames/`：MiniGame Protocol + FishingGame 5 阶段状态机
- `server.py`：`GET /api/minigame/config`（下发签名种子）+ `POST /api/minigame/feed`（验签发奖）
- `FishingGame.tsx`：前端本地 PRNG 跑完整游戏，零延迟交互
- `MiniGameHost.tsx`：streaming 3-15s 显示入口，>15s 自动展开
