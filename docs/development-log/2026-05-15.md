### 问题 14：Turn 级 Human-in-the-Loop (HITL) 机制

- **需求**：工具执行过程中需要暂停，等待用户通过前端卡片输入额外参数（支持文本、图片上传、录音）
- **方案**：Turn 级暂停 — 工具抛出 `RequiresHumanInput` → loop 通过 `HumanInputGate` 暂停 → 前端渲染交互卡片 → 用户提交后 loop 恢复
- **核心新增**：
  - `agent_core/core/human_input.py`：`RequiresHumanInput` 异常 + `HumanInputGate`（asyncio.Future 同步原语）
  - `agent_core/core/events.py`：`HumanInputRequired` 事件
  - `agent_core/core/tool_runner.py`：serial 模式捕获异常，yield 事件后 await gate
  - `agent_core/core/agent.py`：`provide_human_input()` 接口 + abort 时 cancel 所有 pending future
- **SSE 层**：`POST /human-input` 端点，前端卡片支持 text/textarea/image_upload/audio_record
- **验证**：
  - 单元测试：103 passed（含 loop tools 测试，确认无回归）
  - 核心流程验证：`ToolExecutionStart` → `HumanInputRequired` → gate.provide_input → `ToolExecutionEnd` 序列正确
  - 新增示例工具：`agent_core/tools/local/confirm.py`，LLM 调用 `confirm` 时自动触发 HITL 卡片
### 问题 15：HITL 验证修复

- **问题**：前端未渲染 HITL 交互卡片，请求超时
- **根因**：`Agent` 默认 `tool_execution="parallel"`，而 HITL 处理逻辑只实现了 `serial` 分支。`parallel` 模式下 `RequiresHumanInput` 被 `_run_tools_parallel` 的 `asyncio.gather` 当作未捕获异常抛出，导致整个 loop 崩溃
- **修复**：`scene/http_sse/chat_assistant.py` 创建 Agent 时显式设置 `tool_execution="sequential"`
- **额外修复**：`agent_core/core/tool_runner.py` 的 `_run_single_tool` 中，在 `except Exception` 之前先 `except RequiresHumanInput: raise`，防止 broad except 吞掉 HITL 信号
- **变更文件**：`scene/http_sse/chat_assistant.py`, `agent_core/core/tool_runner.py`
