# 2026-06-15 开发日志

## 本日工作：H5 前端组件标准化迁移 (Phase 1 + 1.5 + Phase 2)

### 变更类型：重构 / 标准化

### 摘要

用 Radix UI headless primitives + lucide-react 系统性地替换手写 UI 组件，消除 5 种折叠实现、手写 Icon/Toast/ConfirmDialog，以及 toggle/switch/tooltip/tabs/side-drawer 的手动实现。

### Phase 1 + 1.5: 折叠/弹窗/提示/图标

| 变更 | 文件 | 说明 |
|------|------|------|
| 新增依赖 | `package.json` | + `@radix-ui/react-collapsible` `@radix-ui/react-alert-dialog` `@radix-ui/react-toast` `lucide-react` |
| 新增 Radix 样式层 | `src/theme/radix-overrides.css` | z-index 归一化、focus-visible、data-state 动画、lucide-spin、collapsible/toast/dialog 动画 |
| 新增折叠封装 | `src/components/shared/CollapsibleSection.tsx` | 薄封装 `@radix-ui/react-collapsible`，共享 `.collapsible-content` 动画 |
| 折叠统一 | `ChannelsPage.tsx` `ConnectorsPage.tsx` `ExpertsPage.tsx` `KnowledgePage.tsx` `SkillsPage.tsx` `EvolutionPanel.tsx` | 5 个 set-toggle + 1 个 boolean 折叠统一为 Radix Collapsible，删除手写 aria-expanded |
| ConfirmDialog | `ConfirmDialog.tsx` `.css` | 用 `@radix-ui/react-alert-dialog` 替换，保留 `useConfirmStore` API |
| Toast | `Toast.tsx` | 用 `@radix-ui/react-toast` 替换，使用 `Toast.Provider`/`Viewport` |
| Icon | `Icon.tsx` | 用 `lucide-react` 组件映射 53 个 name，保留 `ICON_SIZES` 和 props API |
| 主入口 | `main.tsx` | 追加 `import './theme/radix-overrides.css'` |
